🧭 Daily Standups

Daily standup timer for Slack

Keep a 15-minute standup at 15 minutes. HuddlePace gives the team one visible clock in the Huddle thread, so the facilitator no longer has to be the one who interrupts.

Install to Slack

Why standups run long

A standup planned for 15 minutes stretches when one topic grows and nobody owns the clock. A shared progress bar makes the remaining time visible to everyone at once.

Set up a 15-minute standup

Run /pace, set 15 minutes and split the time into modules. A common split:

  • Context, 15% (2 min 15 s)
  • Updates, 60% (9 min)
  • Blockers, 25% (3 min 45 s)

Tick Save as template and the next standup starts from the same channel, speakers, duration and modules in one click.

Nudges that stay private

The active speaker gets a Slack DM at the midpoint and with one minute left, so nobody is called out in front of the team. Whoever finishes early taps Next Module to hand the spare time forward.

Check how the team is doing

/pace report 30 shows timebox adherence and session logs for the last 30 days, which is useful evidence for a retro.
