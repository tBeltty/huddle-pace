Questions from agencies

How do I keep a client call inside its time budget?

Split the call into modules with fixed percentages and start a session. The progress bar shows everyone how much of each block is left.

What is Just Chatting mode?

A mode for the casual part of a call. It freezes the formal metrics while the Huddle stays open.

Can I reuse the same agenda every week?

Yes. Save it as a template and start the next sync from it in one click.

Does HuddlePace record audio?

No. It records 0% audio and stores no transcripts. It keeps only the timestamps and the agenda modules it needs to run the timer.
