Split any call by percentage

Choose a duration and divide it into up to 10 modules. The percentages must add up to 100, and HuddlePace turns them into minutes.

Huddle timer questions

What is a Slack Huddle timer?

A tool that tracks how long a Huddle has run against a planned duration. HuddlePace does it with a progress bar in the Huddle thread and private alerts for the speaker.

Does HuddlePace record audio?

No. It records 0% audio and stores no transcripts. It keeps only the timestamps and the agenda modules it needs to run the timer.

How many modules can an agenda have?

Up to 10. The percentages must add up to 100 before the session can be saved.

What happens when everyone leaves the Huddle?

The session ends on its own and HuddlePace posts a summary comparing the scheduled and the actual duration.
