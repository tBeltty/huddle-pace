# Paragraph Structure

A paragraph boundary check: does this block of sentences cover one beat, or does it quietly
run through two (or more) that belong apart? Bilingual by design — the signals below are about
narrative structure, not language-specific grammar, so the same checklist applies to Spanish
and English drafts without translation.

## Why this exists

Proofreading (grammar/punctuation) and copy-editing (clarity/message) both operate *within* a
paragraph's existing boundaries — neither asks whether the boundary itself is in the right
place. A paragraph can be grammatically perfect and message-clear in every sentence and still
be structurally wrong, because it silently jumps between two things that deserve separate
paragraphs. That gap is what this check closes.

**Origin (2026-09-07):** a paragraph moved from a childhood memory ("de niño acompañaba a mis
padres...") to an adult habit and its product connection ("de ahí nació mi idea del Carrito de
mercado...") without a break. It read fine sentence-by-sentence — the seam only became obvious
when the owner asked "¿no crees que eso merece un salto de línea?" No mechanical or message
check would have caught it; both operate below the paragraph level.

## Signals that a paragraph wants a break

Check for these at every sentence boundary inside a multi-sentence paragraph. Any one of them
present is a candidate split point — not automatic, but worth flagging:

| Signal | Example (from the origin case) |
|---|---|
| **Time shift** | "de niño" → "de adulto" — different life stage, different scene |
| **Scene/location shift** | supermarket with parents → home entering data into Excel |
| **Subject-role shift** | the writer as a child observing a habit → the writer as an adult applying it → the product that replaced it |
| **A sentence that resolves the paragraph's opening tension, followed by a new one** | "de ahí nació mi idea del Carrito de mercado" resolves the backstory; what follows (how the feature works today) is a new beat, not a continuation |
| **The paragraph would still make sense read as two, with nothing lost** | if inserting a break between two sentences loses no connecting logic, that's evidence they were never one thought |

## What is NOT grounds for a split

Don't split on sentence *count* alone, or because a paragraph looks long on the page. A long
paragraph that stays on one beat (one scene, one idea, one continuous cause-and-effect chain)
is fine — length is not the signal, a beat change is. Splitting a single coherent thought into
two paragraphs just to shorten them fragments the read for no reason.

## Process

1. Read the paragraph once for its throughline — what's the one thing it's establishing?
2. Walk each sentence boundary and check it against the signals table above.
3. Where a real shift exists, propose the split and show both resulting paragraphs — let the
   writer confirm, since some beat changes are deliberate compression, not an oversight.
4. This check runs independently of `proofreading` and `copy-editing` — a paragraph can pass
   both of those and still need this one, and vice versa.
